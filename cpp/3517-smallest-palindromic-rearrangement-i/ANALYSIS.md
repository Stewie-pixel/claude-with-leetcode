## Concept

A palindrome reads the same forward and backward.  
If we know the left half of the palindrome, the right half is forced to be its reverse, and the middle character (if any) is the one that appears an odd number of times.  
To obtain the **lexicographically smallest** palindrome we therefore want the left half to be as small as possible in lexicographic order.  
Because only lowercase English letters appear, we can greedily place the smallest possible characters in the left half, using as many copies of each letter as we can (i.e., `freq[ch] // 2`). Any leftover odd count becomes the middle character.

## When to Use It

Use this greedy strategy when you see:
- A string that is guaranteed to be a palindrome (or you can reorder characters freely).
- The task is to construct the smallest/largest palindrome (or any palindrome) from a multiset of characters.
- The alphabet size is small (e.g., lowercase letters) allowing counting‑sort‑like solutions.

## Template

```python
# Greedy construction of the smallest palindrome from a multiset of chars
def smallest_palindrome(s: str) -> str:
    # 1. Count frequencies
    freq = [0] * 26               # for 'a'..'z'
    for ch in s:
        freq[ord(ch) - ord('a')] += 1

    # 2. Build left half in lexicographic order
    left_parts = []
    for i in range(26):
        ch = chr(ord('a') + i)
        left_parts.append(ch * (freq[i] // 2))
    left = ''.join(left_parts)

    # 3. Determine the middle character (if any)
    middle = ''
    for i in range(26):
        if freq[i] % 2 == 1:
            middle = chr(ord('a') + i)
            break                # only one odd count can exist in a palindrome

    # 4. Right half is reverse of left
    right = left[::-1]

    return left + middle + right
```

### Approach 1: Brute Force (Backtracking)

**Algorithm**
1. Count the frequency of each character.
2. Use backtracking to fill the palindrome from the outermost positions inward:
   - At each step, try every character that still has at least two remaining copies (to place symmetrically) in increasing lexicographic order.
   - Decrease its count by 2, place it at the current left and right positions, and recurse.
   - When the length is odd, the middle position gets the sole remaining odd‑count character.
3. The first complete palindrome generated by this ordered search is the lexicographically smallest.

**Implementation**

```python
from collections import Counter

class Solution:
    def smallestPalindrome(self, s: str) -> str:
        n = len(s)
        freq = Counter(s)
        res = [''] * n
        l, r = 0, n - 1

        def backtrack(pos_left: int, pos_right: int) -> bool:
            if pos_left > pos_right:          # filled all positions
                return True
            if pos_left == pos_right:         # middle slot for odd length
                for ch in map(chr, range(ord('a'), ord('z') + 1)):
                    if freq[ch] == 1:
                        res[pos_left] = ch
                        freq[ch] -= 1
                        return True
                return False

            # try to place a pair (ch, ch) at (pos_left, pos_right)
            for ch in map(chr, range(ord('a'), ord('z') + 1)):
                if freq[ch] >= 2:
                    # choose ch
                    res[pos_left] = res[pos_right] = ch
                    freq[ch] -= 2
                    if backtrack(pos_left + 1, pos_right - 1):
                        return True
                    # backtrack
                    freq[ch] += 2
            return False

        backtrack(l, r)
        return ''.join(res)
```

**Complexity Analysis**
- Time complexity: O(26^⌊n/2⌋) in the worst case — we try every possible pair at each step (exponential).
- Space complexity: O(n) for the result array plus O(1) for the frequency table (constant 26).

### Approach 2: Greedy with Sorting (O(n log n))

**Intuition**
Since the left half determines the whole palindrome, we can make it as small as possible by sorting the characters that will appear in the left half.  
For each character we can use `freq[ch] // 2` copies on the left side; any leftover odd count becomes the middle character. Sorting the left half yields the smallest lexicographic prefix.

**Algorithm**
1. Count frequencies of each letter.
2. Take the first `n // 2` characters of the string, sort them → this forms the left half.
3. The middle character (if `n` is odd) is the original middle character of the input palindrome (it is guaranteed to be the only odd‑count char after sorting the halves).
4. Mirror the left half to obtain the right half.

**Implementation**

```python
class Solution:
    def smallestPalindrome(self, s: str) -> str:
        n = len(s)
        # left half = first floor(n/2) chars, sorted
        left = sorted(s[: n // 2])
        left_str = ''.join(left)

        # middle character (if any)
        middle = s[n // 2] if n % 2 else ''

        # right half is reverse of left
        right_str = left_str[::-1]

        return left_str + middle + right_str
```

**Complexity Analysis**
- Time complexity: O(n log n) — sorting the left half dominates.
- Space complexity: O(n) — for the sorted list and the resulting strings.

### Approach 3: Greedy with Counting Sort (O(n))

**Intuition**
Because the alphabet consists of only 26 lowercase letters, we can avoid the `O(n log n)` sorting step by constructing the left half directly in lexicographic order using a frequency array.  
We add `freq[ch] // 2` copies of each character from `'a'` to `'z'` to the left half.  
The first character with an odd frequency (if any) becomes the middle character.  
This yields the smallest possible left half, and thus the smallest palindrome, in linear time.

**Algorithm**
1. Count frequencies of each letter in an array of size 26.
2. Iterate from `'a'` to `'z'`:
   - Append `freq[i] // 2` copies of the current character to the left half.
   - Remember the first character with an odd frequency as the middle character.
3. Form the right half by reversing the left half.
4. Concatenate left + middle + right.

**Implementation**

```python
class Solution:
    def smallestPalindrome(self, s: str) -> str:
        freq = [0] * 26               # frequency for 'a'..'z'
        for ch in s:
            freq[ord(ch) - 97] += 1

        left_parts = []
        middle = ''

        for i in range(26):
            ch = chr(97 + i)
            cnt = freq[i]
            left_parts.append(ch * (cnt // 2))
            if middle == '' and cnt % 2 == 1:
                middle = ch

        left = ''.join(left_parts)
        right = left[::-1]
        return left + middle + right
```

**Complexity Analysis**
- Time complexity: O(n) — one pass to count, one pass over the 26‑letter alphabet to build the answer.
- Space complexity: O(n) — for the output string (the frequency array is O(1)).

**Summary**  
- The greedy counting‑sort approach builds the left half in lexicographic order using only the character frequencies.  
- It runs in O(n) time and O(1) extra space (ignoring the output), which is optimal for the given constraints.  
- This method generalizes to any “smallest/largest palindrome from a multiset” problem with a bounded alphabet.
